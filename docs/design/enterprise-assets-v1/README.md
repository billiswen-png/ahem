角色集合由左至右、由上至下：管理者、Operator、Viewer、Observer；
受限內容人員、客服、空資料、拒絕存取；載入、正常、效能下降、未知。
此圖是集合圖，尚未切成12個独立檔案。透明檢查：alpha extrema 0–254，
788130個完全透明像素，784734個部分透明像素。柔邊可能在不同底色產生光暈，
應先於實際背景試貼；不建議以此圖取代小尺寸的程式圖示。

按鍵圖文字已視覺核對：包含進入工作台、登出、重新整理、會議分析、內容與授權、
服務狀態、存取稽核、匯入事件檔、查看內容、管理授權、允許閱覽、撤銷閱覽、
確認讀取、刪除。表單中的檔名為 AI 示意 `meeting_20240520.ahem`，
實際只使用 `.jsonl` 事件檔；「內容類別」應對應現有「會議政策」。
眼睛／移除圖示為設計示意，現有程式未必提供對應操作。

接入規則：背景與大型插畫可作 raster；按鍵／文字／焦點框以 HTML/CSS 實作，
保留真正 disabled、keyboard focus、ARIA 與角色授權，不把整張按鍵圖當可點熱區。
圖片載入前保留純米白背景；不將大圖嵌入每個 SSE 事件或音訊流程。
不用 AI 圖示宣稱登入整合、合規認證或服務健康已完成。
